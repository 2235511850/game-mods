# CP77 游戏变速（v1.1.0）

《赛博朋克 2077》CET Lua 插件。不注入档、不改 pak、不碰 redscript，
运行时通过引擎的**时间膨胀**接口改世界时间流速。

**已在实机验证**：游戏 2.5 / CET 1.38.1 / AMD RX 9070（FSR4 + 光追，路径追踪关）

---

## 它做什么

| 项目 | 原版 | 本插件 | 说明 |
| --- | --- | --- | --- |
| 世界时间流速 | 固定 1.0 | **0.1 – 10.0** | 走 `SetTimeDilation`，动画/物理/AI/任务计时同步缩放 |
| V 自身速度 | 永远跟随真实时间 | **可跟随 / 可豁免** | 关掉豁免就是"子弹时间"，打开就是"跑图加速" |
| 循环档位 | 无 | **5 档可配** | 按 F6 在自定义档位间切换，比一句句调滑条快 |
| 屏幕反馈 | 无 | **原生角标** | 走 `UI_Notifications` 通道，字体和淡入淡出都是游戏自己的 |
| 配置持久化 | 无 | **config.json** | 改完档位不用每次重设 |

核心只有两个引擎调用：

```lua
ts:SetTimeDilation("modGameSpeed", 2.0)              -- 往膨胀栈写一格
ts:SetIgnoreTimeDilationOnLocalPlayerZero(false)     -- 让 V 也一起变
```

第二行是分水岭：`false` = V 跟世界一起加速（跑图需要）；`true` = 只有世界变（拍照、纯看动画）。
F8 就是在切这个。

## 安装

1. 装 **Cyber Engine Tweaks**（CET）
2. 把 `init.lua` 放到
   `Cyberpunk 2077/bin/x64/plugins/cyber_engine_tweaks/mods/GameSpeedControl/init.lua`
3. 启动游戏，进存档

**热键**：`bindings.json` 里已预写 F6/F7/F8 的正确编码，实测无需手动绑定。
但 CET 默认开 `RemoveDeadBindings`，如果哪次启动后发现热键条目变成 `null`，
说明注册失败被清了 —— 到 CET 面板（`~` 或 Ctrl+0）→ Hotkeys 里点一下重新绑即可。

**怎么确认跑起来了**

- 设置 → Mods 里多一页「游戏变速」→ 插件活着
- 按 F6，屏幕上方弹「速度 1.5× · 2/5」→ 热键通了
- 日志 `mods/GameSpeedControl/debug.log` 出现 `热键命中: cycle` → 按键确实进来了

**卸载**：删掉 `mods/GameSpeedControl/` 整个目录，游戏完全恢复原样。

## 配置

设置页三个分组，改动即时生效：

| 分组 | 控件 | 说明 |
| --- | --- | --- |
| 倍率与手感 | 游戏速度倍率（1.0–5.0） | 直接拖，立刻变速 |
| | 玩家同步加速（开关） | 同 F8 |
| | 切到下一档 / 回到原速 | 不依赖热键的按钮，同 F6 / F7 |
| F6 循环档位 | 循环档位数（1–5） | 只在这几个档里循环，后面的不参与 |
| | 档位 1 – 档位 5（0.1–10.0） | 改的是循环序列，不立刻变速；当前倍率正好等于该档时会跟着变 |
| | 恢复默认档位 | 回 1.0 / 1.5 / 2.0 / 3.0 / 5.0 |

改完档位会写进同目录的 `config.json`（相对路径），重启保留。

控制台入口：`GetMod("GameSpeedControl").SetScale(2.0)`

## 走过的弯路（省得你重踩）

**1. `registerHotkey` 必须写在脚本顶层，不能放进 `onInit` 回调。**

CET 只在**脚本加载那几毫秒**把这些 API 注入环境，等 `onInit` 执行时全局已经撤掉了。
表现是：`init.lua:138: attempt to call global 'registerHotkey' (a nil value)`，
而且它会把整个 `onInit` 静默中断 —— 热键没注册上、设置页也没建，
在游戏里就是"按 F6 没反应，Mods 菜单里还找不到"。

对照办法：本机所有能正常工作的插件（`custom_fast_travel_pins`、`CrashWatch`）
都是在顶层直接调的。

**2. 主菜单阶段绝对不能碰引擎时间系统，`pcall` 拦不住。**

`Game.GetTimeSystem()` 在主菜单阶段**返回的不是 nil**，但此时它还没挂到真实会话上，
调 `UnsetTimeDilation` 会触发**原生层访问违例**，进程直接崩，`pcall` 兜不住
（那不是 Lua 错误）。

判定会话真的起来了，看 `Game.GetPlayer()` 是否为 nil。本插件的做法是：
倍率为 1.0 且从未改过引擎时，一个原生调用都不做；每次调用前先确认玩家实体存在。

**3. CET 的 io 沙箱拒收绝对路径，返回 `EINVAL(22)`。**

```lua
io.open("C:/.../mods/GameSpeedControl/config.json", "w")   -- 返回 nil, 22
io.open("config.json", "w")                                 -- 成功
```

相对路径的基准正好是 mod 自己目录。本机 `MuchBetterAI`、`custom_fast_travel_pins`、
`BetterLootMarkers` 全用相对路径，文件也都落在各自目录里 —— 这是唯一可行写法。

**4. `bindings.json` 里的值不是 VK 码本身。**

CET 把最多 4 个 16 位 VK 码**从高位往低位**打包进一个 uint64，单键就是 `VK << 48`：

| 热键 | 错误写法 | 正确值 |
| --- | --- | --- |
| F6 | `117` | `32932572275146752` |
| F7 | `118` | `33214047251857408` |
| F8 | `119` | `33495522228568064` |

写裸 VK 码不会报错，只是静默无效。

**5. 绑定条目"凭空消失"先怀疑注册失败，不是编码问题。**

CET 启动时会清理没被成功注册的绑定（`RemoveDeadBindings`）。
热键注册失败 → 整条绑定被当成无效删掉 → 看起来像"文件被我写坏了"。
实际上注册修好后，写进去的值就会保留。

**6. 滑条回调是连续的，不能每次都弹提示。**

拖一次档位滑条会连续触发几十次回调，每次 `notify` 就是几十条消息刷满屏幕。
本插件加了约 1.2 秒的提示限流，但速度依然实时跟手。

**7. 载具物理被引擎硬编码忽略 dilation。**

`SetTimeDilation` 对走路、跑步、物理、AI 都生效，**唯独载具不吃这一套**。
所以"开车跑图加速"做不到，这是引擎层面的限制，不是插件 bug。

**8. 语音是实时音频流，不随膨胀变速。**

世界快 2 倍，台词还是原速播完，结果就是语速和画面脱节、台词被截断。
**1.5–2.0 是过场动画的体感上限**，超过 2.0 口型开始对不上。纯赶路可以开到 3.0+。

**9. dilation 是栈，不是全局变量。**

斯安威斯坦、克伦齐科夫、破解界面、教程各占一格。必须用**独有的 reason 名**
（这里用 `modGameSpeed`），否则会和沙坦互相覆盖 —— 你开沙坦会顶掉我的值，
反之亦然。用独立 key 时两者可以叠加，叠加后可能"人物超速"，按 F7 清掉即可。

## 已知限制

- **开车不会变快**，原因见上第 7 条
- **配音不加速**，倍率超过 2.0 口型会漂
- 过场、读档、快速移动之后引擎会清空膨胀栈，插件每秒补挂一次，所以倍率是"粘住"的
- 只改内存里的时间流速，不落盘；每次进游戏都从 1.0 开始，靠 `config.json` 恢复档位
- 只在 CET 1.38.1 + 游戏 2.5 上验证过；CET 换大版本后 API 可能变

## 文件说明

```
CP77_GameSpeedControl/
├── README.md            ← 本文件
├── manifest.json        ← 元数据 + 安装路径映射（CET 的路径比 UE4SS 深，写在 map 里）
├── Scripts/
│   └── init.lua         ← 唯一源码，中文界面
├── _test/
│   └── test_gsc.py      ← lupa 桩环境回归测试，不进游戏就能跑
└── reference/           ← 逆向笔记，不进发布包
```

**源码只有一份**，不设 payload 副本。安装时按 `manifest.json` 的
`install.map` 拷过去，避免两份不同步（本仓库的 PBZ 那个 mod 就吃过
"打包源与工程源不同步"的亏）。

### 跑离线测试

需要 `pip install lupa`。改完 Lua 先跑这个，别直接进游戏试错：

```bash
cd CP77_GameSpeedControl/_test
python test_gsc.py
```

### 部署到游戏

```bash
cp CP77_GameSpeedControl/Scripts/init.lua \
   "/c/app/Steam/steamapps/common/Cyberpunk 2077/bin/x64/plugins/cyber_engine_tweaks/mods/GameSpeedControl/init.lua"
```

改完核对 md5，两边一致才算部署成功。
